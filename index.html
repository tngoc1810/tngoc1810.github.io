03 / How I approach a case

Evidence before conclusions.

01 · Establish the source

Start with what is recorded.

Identify the host, provider, time window and original artifact. Keep enough context to return to the same record.

02 · Connect the activity

Follow the next useful pivot.

Correlate processes, identities and traffic. Separate an observed relationship from one that is only plausible.

03 · Make it reviewable

Explain what remains unknown.

Write the reasoning, alternative explanations and next checks. A useful handoff should survive another analyst's review.
